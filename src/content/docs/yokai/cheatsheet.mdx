First set up the repository using the [koi cheatsheet](/koi/docs/cheatsheet).

## Doctor & run

Before launching Yokai, finish `/junji plan` and `/junji refine` in your coding agent. The run needs a populated backlog and working sensors.

```bash
koi doctor
koi doctor --probe
yokai          # or: yokai --once
yokai --guarded
yokai --host   # force host even if sandbox enabled
yokai --headless
yokai --max-cost 5.00
yokai --max-iters 3
yokai --theme hiru   # yoru | hiru | terminal  (yoi and asa alias to yoru)
```

```bash
# develop without installing (repo root)
cargo run -p koi -- doctor --probe
cargo run -p yokai --
```

## Sandbox: Apple

```bash
container system start
koi setup --sandbox on --backend apple --agent opencode
koi init                # agent: opencode
container build -f .koi/Dockerfile.sandbox -t koi-<repo>-sandbox .
# ensure .koi/sandbox.yml image: matches
koi doctor --probe
yokai
# first time: auth inside the VM
container exec -it yokai-<repo> opencode   # then /connect
```

```bash
# recreate after image rebuild / agent change
container stop yokai-<repo> && container rm yokai-<repo>
yokai
```

Walkthrough: [Launch a sandbox](/yokai/docs/sandbox/launch#apple-container).
## Sandbox: Docker sbx

```bash
# Docker Desktop must be running (docker.sock present)
sbx login
koi setup --sandbox on --backend docker --agent opencode
koi init                # agent: opencode
docker build -f .koi/Dockerfile.sandbox -t koi-<repo>-sandbox .
# ensure .koi/sandbox.yml image: matches
# optional: sbx secret set -g openai   # or anthropic / openrouter / …
koi doctor --probe
yokai
```

```bash
# recreate after image rebuild
sbx rm yokai-<repo>       # exact flag/name: see sbx --help
yokai
```

Walkthrough: [Launch a sandbox](/yokai/docs/sandbox/launch#docker-sandboxes).
