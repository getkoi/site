## Independent entry points

[Framework ADR-0007](https://github.com/getkoi/koi/blob/main/docs/adr/0007-independent-junji-and-yokai-setup.md) defines standalone Junji and the file handoff. [Driver ADR-0053](https://github.com/getkoi/koi/blob/main/crates/yokai/docs/adr/0053-owned-onboarding-and-reviewed-gate.md) supersedes ADR-0015/0032 with Yokai-owned onboarding, layered settings and reviewed sensors.

[Framework ADR-0008](https://github.com/getkoi/koi/blob/main/docs/adr/0008-reviewed-sensors-and-phase-assessments.md) and [driver ADR-0054](https://github.com/getkoi/koi/blob/main/crates/yokai/docs/adr/0054-skill-backed-preparation.md) add shared helper policies, reviewed temporary smoke checks, compact gate fingerprints and reviewed phase assessments.

[Authoritative assessment YAML](https://github.com/getkoi/koi/blob/main/crates/yokai/docs/adr/0055-authoritative-assessment-mapping.md) removes assessment fingerprints and duplicate runtime approval. Complete skill-approved mappings are immediately usable by the driver.
