This page lists common commands. For the concepts behind them, see the [Sandbox overview](/docs/sandbox/overview). For more detail, see [yokai run](/docs/yokai/run), [configuration](/docs/reference/configuration), and [CLI reference](/docs/reference/cli).

## Install (once)

```bash
# from a koi checkout
./install.sh
# ensures koi + yokai on PATH (~/.cargo/bin)
```

```bash
# OpenCode on the host
npm install -g opencode-ai@latest
opencode    # then /connect
```

```bash
# Claude (default agent) — log in before yokai
claude auth login
claude auth status
```

```bash
# Codex — API key, or ChatGPT login via the Codex CLI
export CODEX_API_KEY=…   # or OPENAI_API_KEY; NO_BROWSER=1 in sandbox
npx -y @agentclientprotocol/codex-acp --version
```

## Project setup + init (host-first)

```bash
cd /path/to/repo
koi setup               # once per repo — .koi/sensors/ + .koi/sandbox.yml
# sandbox: No
koi init                # per effort — .koi/run/ config
# agent: opencode
```

```bash
koi setup --sandbox off --yes                # non-interactive project home
koi init --yes                               # non-interactive defaults
koi init --agent cursor --permission approve-all
```

```bash
# in the coding agent
/junji begin
```

## Doctor & run

Before launching Yokai, finish `/junji plan` and `/junji refine` in your coding agent. The run needs a populated backlog and working sensors.

```bash
koi doctor
koi doctor --probe
yokai          # or: yokai --once
yokai --guarded
yokai --host   # force host even if sandbox enabled
yokai --headless
yokai --max-cost 5.00
yokai --max-iters 3
yokai --theme hiru   # yoru | hiru | terminal  (yoi and asa alias to yoru)
```

```bash
# develop without installing (repo root)
cargo run -p koi -- doctor --probe
cargo run -p yokai --
```

## Sandbox: Apple

```bash
container system start
koi setup --sandbox on --backend apple --agent opencode
koi init                # agent: opencode
container build -f .koi/Dockerfile.sandbox -t koi-<repo>-sandbox .
# ensure .koi/sandbox.yml image: matches
koi doctor --probe
yokai
# first time: auth inside the VM
container exec -it yokai-<repo> opencode   # then /connect
```

```bash
# recreate after image rebuild / agent change
container stop yokai-<repo> && container rm yokai-<repo>
yokai
```

Walkthrough: [Launch a sandbox](/docs/sandbox/launch#apple-container).

## Sandbox: Docker sbx

```bash
# Docker Desktop must be running (docker.sock present)
sbx login
koi setup --sandbox on --backend docker --agent opencode
koi init                # agent: opencode
docker build -f .koi/Dockerfile.sandbox -t koi-<repo>-sandbox .
# ensure .koi/sandbox.yml image: matches
# optional: sbx secret set -g openai   # or anthropic / openrouter / …
koi doctor --probe
yokai
```

```bash
# recreate after image rebuild
sbx rm yokai-<repo>       # exact flag/name: see sbx --help
yokai
```

Walkthrough: [Launch a sandbox](/docs/sandbox/launch#docker-sandboxes).
