## Junji alone

```bash
npx skills add getkoi/koi --skill junji
```

```text
/junji begin
/junji plan
/junji refine
/junji next          # repeat per phase
/junji consolidate  # all phases done; human-approved collapse
```

Run the documented verification commands and commit each phase. Sensor scripts and runtime tags are
optional. Human gates, dependency order and standing directives remain binding.

## Optional Yokai

From the framework checkout, `./install.sh` installs Yokai. Then, in the Junji-prepared project:

```bash
yokai --once            # guided missing setup, review gate, offer to run one phase
yokai                   # later runs reuse settings
yokai          # review commands, smoke temporary scripts, approve gate
yokai           # review per-phase tiers and strategies in effort YAML
yokai    # interactive runtime and sandbox settings
yokai doctor --probe    # optional diagnostics
yokai migrate           # existing legacy settings only
```

Reusable settings: `.koi/yokai.yml`. Optional effort differences: `.koi/run/yokai.yml`.
Headless startup never prompts or authors setup. Bare runs halt at human-gated phases; explicit
`--allow-gated` authorizes them for that invocation without overriding standing directives.
